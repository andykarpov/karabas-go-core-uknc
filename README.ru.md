# Ядро УКНЦ (Электроника МС-0511) для Karabas Go / Mini / Mini G

[English version](README.md)

Учебный компьютер **УКНЦ** (Электроника МС-0511, два процессора 1801ВМ2) на платах семейства Karabas Go
(Xilinx Spartan-6 XC6SLX25): ЦП и ПП с памятью и видео, четыре дисковода (образы DSK, на Go физический
дисковод), картридж жёсткого диска IDE с WD ROM (файлы образов), мышь и часы Kakave, три AY платы Aberrant,
бипер, оба порта Covox и последовательный порт C2.

Один файл ядра `uknc.kg` для всех плат (прошивка 26110415 или новее).

| Плата | Видео | Звук |
|---|---|---|
| Karabas Go | VGA | I2S ЦАП (PCM5102) |
| Karabas Mini | HDMI | HDMI, аналоговый выход (sigma-delta) |
| Karabas Mini G | HDMI | HDMI, I2S ЦАП (PCM5102) |

## Использование

Скопируйте `uknc.kg` на SD-карту (SD1), образы дисков в `/mc0511-media` (папка файловых пунктов по
умолчанию). OSD открывается Menu (Win) + Esc.

| Пункт | |
|---|---|
| FDD0, HDD0 | образ DSK дисковода 0, образ IMG жёсткого диска (нужно Hard disk / HDD controller On) |
| Kakave mouse, RTC controller | картридж Kakave+: USB-мышь, часы реального времени |
| Color | RGB / BGR |
| Run SAV | запуск программы `.SAV` в RT-11 (прошивка 26110716 или новее; 26110520..26110715 перезагружается при выборе файла): из `RT11BASE.DSK` (или `BASERT11.DSK`, как он назван в `soft/` tang-uknc) в `/mc0511-media`, системного диска RT-11, который вы кладёте туда сами, собирается диск `RT11SAV.DSK`, монтируется в FDD0, и машина сбрасывается; предыдущий диск остаётся как `RT11OLD.DSK` |
| Reset (F12) | сброс машины |
| Sound | громкость, бипер, Covox (порт 177372, 177100 LPT или оба), AY1-AY3, стерео, фильтр, old freaks |
| Floppy drives | контроллер FDD, образы FDD1-FDD3, защита записи каждого дисковода, физический дисковод (Go: A-D) |
| Hard disk | контроллер HDD, защита записи, формат образа (авто / прямой / инверсный), задержка HDD |

Клавиатура: буквы и цифры стоят на своих латинских местах (раскладка ЙЦУКЕН УКНЦ: Q = Я, W = В и т. д.),
знаки и служебные клавиши как в UKNCBTL:

| ПК | УКНЦ | ПК | УКНЦ |
|---|---|---|---|
| `-` | `- =` | `;` | `: *` |
| `=` | `Ч ^` | `'` | `Ю @` |
| `` ` `` | `; +` | `\` | `Э \` |
| `[` `]` | `Ш [` `Щ ]` | Home | `Ъ` |
| Esc | АР2 | Caps Lock | ФИКС |
| Ctrl / Alt / правый Alt | УПР / АЛФ / ГРАФ | F1-F5 | К1-К5 |
| F6 / F7 / F8 | ПОМ / УСТ / ИСП | F9, Insert | СБРОС |
| F10, PageUp | СТОП | Delete / End / PageDown | ПОМ / УСТ / ИСП |
| Цифровой блок: цифры, `.`, `-`, `+`, Enter | те же клавиши блока УКНЦ | Цифровой блок: `/` / `*` | `/ ?` / `: *` |

Особенности:

- Раскладка **позиционная**, как в UKNCBTL: клавиша ПК нажимает клавишу УКНЦ на том же месте, а символ
  выбирает УКНЦ по своей клавиатуре. Поэтому знаки с Shift часто другие, чем на ПК: `:` — это `;`
  **без** Shift, Shift+`;` даёт `*`; `=` — Shift+`-`; `+` — Shift+`` ` ``; Shift+2 даёт `"`, а не `@`
  (`@` — клавиша `'`); Shift+`'` даёт `` ` ``. Знаки с Shift на цифрах — как на клавишах УКНЦ
  (Shift+1 = `!`, Shift+3 = `#` и т. д.).
- Клавиша `=` ПК — это `Ч ^`: в режиме ЛАТ она даёт `^` (в шрифте УКНЦ `¬`), в режиме РУС — Ч.
- Num Lock не учитывается: цифровой блок всегда работает как блок УКНЦ. Запятой блока УКНЦ на ПК нет.
- Клавиатура УКНЦ передаёт нажатия по рядам матрицы, и две клавиши одного ряда одновременно держать
  нельзя: при нажатии второй первая считается отпущенной. Отсюда два ограничения: Shift не
  сочетается с 7, 8, 9 и `-` цифрового блока (тот же ряд), а УПР / АЛФ / ГРАФ — с Esc (АР2), Tab, 0 и
  Enter цифрового блока.
- Shift, УПР, АЛФ и ГРАФ всегда передаются машине раньше клавиши, с которой нажаты, и отпускаются
  после неё (УПР+C прерывает программу в RT-11).
- F12 сбрасывает машину (пункт Reset), Menu (Win) + Esc открывает OSD.

### Цвета меню УСТ сохраняются

Цвета меню УСТ (F7: 3 цвет символа, 4 цвет знакоместа, 5 цвет экрана, 6 цвет курсора) остаются после сброса
и выключения: ядро хранит их в EEPROM ядра, файле `/config/uknc.eep` на SD-карте (прошивка с ядрами kgo2).
Зелёный на чёрном: символ 3 (зелёный), знакоместо 1 и экран 1 (чёрный). Остальные пункты меню (VT-52,
формат, рулон, таймер) не сохраняются, как и цвета, заданные программами ESC-последовательностями. Если
удалить `/config/uknc.eep`, снова будет белый на синем.

### Версии RT-11

Если игра сразу останавливается с `*** СТОП ***` (команда HALT), ей может быть нужна другая RT-11: это
не ошибка ядра. Некоторые программы `.SAV` держат код в блоке 0, на адресах 500..776, а монитор RT-11
после загрузки программы записывает её карту блоков в нижнюю память:

| RT-11 | Системный диск | Куда пишется карта |
|---|---|---|
| V05.04 | `BASERT11.DSK` из tang-uknc | 540..557 |
| V05.02 | `sys1002.dsk` | 514..533 |
| V5.01a | `sysimage.dsk` | внутрь монитора, нижняя память не меняется |

Например, `LAND.SAV` с `game.dsk` на V05.04 останавливается с `000556/0000`, а на `sysimage.dsk` работает
([uknc.narod.ru/DSK](https://uknc.narod.ru/DSK/index.htm)). На `game.dsk` есть и другие программы с данными
в 540..557 (SEEKER, GARDEN, CAT, VERT, MAUS, TETUK, DIGGER), их не проверяли. Run SAV загружает системный
диск, который вы положили в `/mc0511-media`, поэтому к нему это тоже относится.
